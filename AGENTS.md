# Instrucciones del repositorio

Este espacio de trabajo se utiliza para desarrollar scripts MikroTik RouterOS a
partir de problemas concretos u objetivos solicitados.

## Compatibilidad con RouterOS

- Cada tarea debe indicar la version exacta de RouterOS sobre la que se
  desplegara el script.
- Si la tarea no indica la version objetivo, se debe solicitar antes de
  desarrollar o modificar el script.
- Antes de desarrollar una solucion, se debe consultar la documentacion oficial
  de MikroTik RouterOS aplicable a la version objetivo.
- Se debe verificar en la documentacion oficial la disponibilidad y sintaxis de
  cada comando, propiedad y comportamiento relevante utilizado.
- No se debe asumir que una configuracion valida para una version de RouterOS
  funciona sin cambios en otra version.
- La solucion debe documentar sus requisitos previos, supuestos, procedimiento
  de despliegue y pruebas de validacion.

## Integridad funcional

- No se admiten simplificaciones, eliminaciones o desactivaciones de funciones
  como solucion para un problema u objetivo.
- Toda solucion debe conservar las funciones existentes y cumplir el objetivo
  completo solicitado.
- No se debe ocultar una incompatibilidad, error o limitacion mediante una
  configuracion de alcance reducido.
- Si existe un conflicto tecnico que impide conservar alguna funcion, se debe
  explicar con evidencia y solicitar una decision explicita antes de cambiar el
  alcance o comportamiento.
- Las soluciones temporales solo se permiten cuando el usuario las solicita o
  aprueba explicitamente, y deben identificarse claramente como temporales.
